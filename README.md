# shape-defenders
A simple tower defence game built in javascript and html

<img width="1033" height="713" alt="image" src="https://github.com/user-attachments/assets/fb879069-01ed-4132-bec1-589a80103b27" />

my main purpose for creating this was to code in a language other than python, and i like tower defence games (not as much as i like vampire survivors)

Features:
-geometrically rendered game with no assets (not fun to code)
-4 unique towers
-4 unique enemies
-enemy scaling system
-tower upgrade and selling

Controls and Hotkeys:
[Click] - select and place towers, inspect stats, and interact with UI elements
[ESC] - deselect tower / toggle pause menu
[Tab] - toggle 2x game speed
[Shift] - toggle auto wave start
[Spacebar] - start next wave
[Q] / [W] / [E] / [R] - select tower types
[U] - upgrade selected tower
[Backspace] - sell selected tower
(cheats)
[Z] - give yourself 100 dodecahedrons
[X] - jump a wave

How to play:
play at https://charliey222.github.io/shape-defenders/ or download the repository and run index.html in any modern browser
